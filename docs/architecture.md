# Architecture

> Status: draft. Decisions are recorded in [adr/](adr/); this page summarises them.

## Principles

- **Proportionate rigour.** Ports and adapters only where a real boundary exists (external feeds). Laravel conventions everywhere else.
- **Rules are enforced, not just written.** Architecture tests fail the build when a boundary is crossed.

## Components

| Component | Role | Decided in |
|---|---|---|
| `VehicleFeed` port | Live positions of a network, whatever the standard | [ADR-0001](adr/0001-feed-ingestion-ports.md) |
| `NetworkCatalog` port | Lines, stops and shapes of a network | ADR-0001 |
| Drivers (MVP) | `gtfs-rt`, `gtfs`, `replay`; `siri-vm`, `netex` only when a network needs them | ADR-0001 |
| Network configuration | One entry per network: drivers, URLs, timezone, id prefix | ADR-0001 |
| Scheduler + queue | Poll feeds, process positions; every write emits `PositionsUpdated` | ADR-0002 |
| Livewire + MapLibre | Map UI; the map and the live store are a framework-agnostic TypeScript module, mounted by Livewire | [ADR-0010](adr/0010-ui-stack.md) |
| Positions endpoint | Browsers ask for what changed, just after the next version is expected (E4.1); the web container's nginx keeps each answer until then, so that pages at the same version cost one PHP request (E4.2); pushing it is in the PRD's *Later* | — |

## Stack

| Layer | Choice | Status |
|---|---|---|
| Framework | Laravel (latest stable), Livewire, Alpine; Inertia + Vue as the planned exit | Decided, [ADR-0010](adr/0010-ui-stack.md) |
| Map | MapLibre GL JS, loaded on the map page only | Decided, [ADR-0011](adr/0011-map-library.md) |
| CSS | Tailwind CSS v4, installed with E3.1; system fonts | Decided, [ADR-0008](adr/0008-css-approach.md) |
| Basemap tiles | OpenFreeMap (no key); self-hosted Protomaps PMTiles as fallback | Decided, ADR-0011 |
| Database | PostgreSQL; PostGIS later, with the first spatial story | Decided, [ADR-0002](adr/0002-database.md) |
| Cache / queue / sessions | Redis; position versions counted by PostgreSQL | Decided, [ADR-0021](adr/0021-redis-and-counted-versions.md) |
| Feed recordings | The poll's vehicle payloads kept per service day on a server volume, archived each night with the catalogue, the last 30 public under `/recordings/` | Decided, [ADR-0022](adr/0022-feed-recordings.md) |
| Destination and line of a trip | Destination from `vehicle.label` where the network's configuration says it is one, sent as is; trip updates not read, the line of positions without a `route_id` (0.03 %) waiting for the trip updates port | Decided, [ADR-0018](adr/0018-destination-from-vehicle-label.md) (supersedes ADR-0017) |
| Line shapes | One GeoJSON file per network, generated by the import only when shapes change, served with an `ETag` | Decided, [ADR-0016](adr/0016-network-shapes.md) |
| Feed decoding | `google/protobuf` runtime, GTFS-Realtime classes generated from the official proto at build time, not committed | Decided, [ADR-0015](adr/0015-gtfs-realtime-library.md) |
| Real-time | Polling aligned on the feed's versions; push (Reverb or SSE) studied and left for later | Decided (2026-10-24), [ideas/realtime-push.md](ideas/realtime-push.md) |
| Hosting | Docker images (`app`, `web`) on one Debian 13 or Ubuntu 26.04 server prepared by an Ansible bootstrap; the host's nginx proxies to them | Decided, [ADR-0020](adr/0020-docker-hosting.md) (replaces [ADR-0012](adr/0012-hosting.md)) |
| Edge | None: the host's nginx serves the site over HTTPS | Decided (maintainer, 2026-10-24): Cloudflare's free plan needs the whole DNS zone, which stays where it is; moved to the PRD's *Later* |
| Quality gates | Pint (`laravel` preset), Larastan (level max), Pest with `arch`, behind `composer qa` | Decided, [ADR-0005](adr/0005-quality-tooling.md) |
| AI review | CodeRabbit, advisory only, configured in `.coderabbit.yaml` | Decided, [ADR-0014](adr/0014-ai-review-bot.md) |
| Local environment | `compose.yaml` with the images production runs (official `php:8.5-fpm-alpine` and `nginx:alpine`; the browser tests on `php:8.5-cli-trixie`, ADR-0020 point 2), versioned app config | Decided, [ADR-0007](adr/0007-local-development-environment.md), amended by ADR-0020 |
| Responsible design | RGAA 4.1.2 AA, RGESN 2024 self-assessment | Decided, [ADR-0006](adr/0006-responsible-design.md) |
| Delivery | Protected `main`, squash merge, release-please, images deployed on release by a restricted SSH command | Decided, [ADR-0004](adr/0004-delivery-workflow.md) |
| Server configuration | Ansible in a container; packages from the distribution's archive; server-local secrets generated on the server | Decided, [ADR-0019](adr/0019-server-configuration.md), amended by ADR-0020 |
